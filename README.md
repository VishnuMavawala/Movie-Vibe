# Movie-Vibe

A sleek and modern iOS application for managing and discovering movies and serials.

## Features
- **Discover**: Browse through a curated list of movies and serials.
- **Search**: Find your favorite titles with ease.
- **Watchlist**: Keep track of what you want to watch.
- **Details**: Get in-depth information about every title.

## Tech Stack
- **Language**: Swift
- **Framework**: SwiftUI
- **Architecture**: MVVM

## Getting Started
1. Clone the repository.
2. Open `Movie-Vibe.xcodeproj` in Xcode.
3. Build and run on your preferred simulator or device.
